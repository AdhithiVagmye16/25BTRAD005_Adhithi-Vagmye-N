
# Lab Experiment 1: Python Environment Setup

## Aim
To install Python and set up a development environment using VS Code, PyCharm, and Jupyter Notebook.

## 1. Installing Python
1. Visit https://www.python.org/downloads/
2. Download the latest stable Python version.
3. Run the installer.
4. Select "Add Python to PATH".
5. Complete the installation.

Verify installation:
```bash
python --version
```

## 2. Installing Visual Studio Code
1. Visit https://code.visualstudio.com/
2. Download and install VS Code.
3. Open VS Code.
4. Go to Extensions (Ctrl + Shift + X).
5. Install the Python extension by Microsoft.
6. Select the installed Python interpreter.

## 3. Installing PyCharm
1. Visit https://www.jetbrains.com/pycharm/
2. Download PyCharm.
3. Install and open the application.
4. Create a New Project.
5. Configure the Python interpreter.
6. Create a Python file and execute it.

## 4. Installing Jupyter Notebook

Install Jupyter using pip:

```bash
pip install jupyter
```

Launch Jupyter Notebook:

```bash
jupyter notebook
```

A browser window will open where Python notebooks can be created and executed.

## 5. Verification Commands

```bash
python --version
pip --version
jupyter --version
```

## Result
Python, VS Code, PyCharm, and Jupyter Notebook installation procedures were completed and the Python environment was verified successfully.
